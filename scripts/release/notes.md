Six-player co-op Pokémon HeartGold. **Bring your own ROM:** GoldLink needs your own unmodified
Pokémon HeartGold (USA) ROM and builds the co-op game from it.

## Downloads

| File | For |
| :--- | :--- |
| `GoldLink-{{VERSION}}-windows.zip` | Windows 10 / 11, 64-bit |
| `GoldLink-{{VERSION}}-linux.tar.gz` | Linux, 64-bit (needs Mono) |

Unpack, start `GoldLink` (`GoldLink.exe` on Windows), choose your ROM the first time, then
press **Play**. The `README.txt` inside says more.

Windows shows an "unknown publisher" warning for this unsigned program: **More info > Run anyway**.

## Compatibility

- Everyone in a room needs this same release.
- Relay protocol **{{WIRE}}**: use a `coop-relay` release for protocol {{WIRE}}.
- The ROM it accepts: SHA-1 `{{ROM_SHA1}}`.
- Bundled: BizHawk {{BIZHAWK_VERSION}}, unchanged.
